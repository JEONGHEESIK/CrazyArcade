# CrazyArcade 강화학습 에이전트

Python 기반 DQN 강화학습 에이전트로 크레이지아케이드 게임을 학습합니다.

## 설치

```bash
cd python_agent
pip install -r requirements.txt
```

## 사용법

### 1. 학습 시작

먼저 C++ 게임을 실행하여 소켓 서버를 시작한 후:

```bash
python train.py
```

### 2. 학습된 모델 테스트

```bash
python test.py --model models/TIMESTAMP/model_episode_1000.pth --episodes 10
```

### 3. TensorBoard로 학습 모니터링

```bash
tensorboard --logdir runs
```

## 프로젝트 구조

```
python_agent/
├── config.py           # 설정 파일 (하이퍼파라미터)
├── model.py            # DQN 신경망 모델
├── agent.py            # DQN 에이전트
├── replay_buffer.py    # 경험 재생 버퍼
├── game_interface.py   # 게임 통신 인터페이스
├── train.py            # 학습 스크립트
├── test.py             # 테스트 스크립트
└── requirements.txt    # 의존성 패키지
```

## 설정

`config.py`에서 다음 항목들을 조정할 수 있습니다:

- **학습률 (LEARNING_RATE)**: 0.0001
- **할인율 (GAMMA)**: 0.99
- **탐험률 (EPSILON_START, EPSILON_MIN, EPSILON_DECAY)**: 1.0 → 0.01
- **배치 크기 (BATCH_SIZE)**: 64
- **메모리 크기 (MEMORY_SIZE)**: 100000
- **최대 에피소드 (MAX_EPISODES)**: 10000

## 학습 과정

1. **초기화**: 에이전트와 게임 환경 연결
2. **에피소드 실행**: 게임 상태 수신 → 행동 선택 → 행동 실행 → 보상 계산
3. **경험 저장**: 리플레이 버퍼에 (상태, 행동, 보상, 다음상태) 저장
4. **학습**: 미니배치 샘플링 후 Q-네트워크 업데이트
5. **타겟 네트워크 업데이트**: 주기적으로 타겟 네트워크 동기화
6. **모델 저장**: 100 에피소드마다 체크포인트 저장

## 보상 구조

- **아이템 획득**: +10 ~ +15
- **상대 처치**: +1000
- **승리**: +1000
- **사망**: -1000
- **시간 패널티**: -0.1 (매 스텝)

## 상태 공간 (600차원)

- 플레이어 정보 (14): 위치, 속도, 물풍선 개수, 파워, 상태, 생존 여부
- 맵 정보 (585): 물풍선 위치, 아이템 위치, 물줄기 위치
- 게임 정보 (1): 게임 시간

## 행동 공간 (6가지)

0. IDLE (대기)
1. UP (위로 이동)
2. DOWN (아래로 이동)
3. LEFT (왼쪽으로 이동)
4. RIGHT (오른쪽으로 이동)
5. PLACE_BOMB (물풍선 설치)

## 학습 팁

1. **초기 학습**: 처음 1000 에피소드는 탐험 위주로 진행됩니다.
2. **수렴**: 5000-10000 에피소드 후 안정적인 성능을 보입니다.
3. **하이퍼파라미터 튜닝**: 학습이 불안정하면 학습률을 낮추세요.
4. **GPU 사용**: CUDA 사용 시 학습 속도가 크게 향상됩니다.

## 문제 해결

### 연결 실패
- C++ 게임이 실행 중인지 확인
- 포트 번호 확인 (기본: 12345)
- 방화벽 설정 확인

### 학습 불안정
- 학습률 감소 (0.0001 → 0.00001)
- 배치 크기 증가 (64 → 128)
- 타겟 네트워크 업데이트 주기 조정

### 메모리 부족
- 배치 크기 감소
- 리플레이 버퍼 크기 감소
- 신경망 크기 축소
